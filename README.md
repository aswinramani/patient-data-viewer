# Patient Data Viewer

A TypeScript frontend in React for viewing parsed clinical documents (C-CDA, with FHIR planned), built on top of the `document-parser` Rust backend.

## Project Layout

```
src/
  components/   # Presentational UI — no fetching, no business logic
  services/     # Data access layer (mock data today, real API fetch later)
  hooks/        # Bridges services + state, exposes { data, loading, error } to components
  utils/        # Pure functions — no side effects (e.g. deriving human-readable summaries)
  types/        # Generated by ts-rs from the Rust backend's structs
  App.tsx
  main.tsx
```

`types/` is kept in sync with `document-parser`'s Rust structs automatically — running `cargo test` in that repo regenerates these files here via `ts-rs` crate.
